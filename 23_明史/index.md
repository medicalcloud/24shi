# 23 明史

『明史』は，明（1368–1644）の正史で，清の張廷玉らが編んだ。底本は清の乾隆年間に改められた異民族の人名・地名の表記を用いており，ここでもそのまま記す。方伎伝は (1) 医療者の伝として訳したので，ここには含めない。嘉靖帝の丹薬，泰昌帝の「紅丸」の事件など，皇帝の服薬の記事が多い。
